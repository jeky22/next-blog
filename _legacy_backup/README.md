# 프론트엔드 개발자 이제찬 - 포트폴리오 웹사이트

5년 차 프론트엔드 개발자 이제찬의 포트폴리오 웹사이트입니다.

## 🚀 기술 스택

- **Framework**: Next.js 14
- **UI Library**: MUI (Material-UI) v5
- **Language**: JavaScript
- **Animation**: Animate.css, React Typist
- **Other**: Fullpage.js, React Slick

## 📋 주요 섹션

1. **Header** - 타이핑 애니메이션을 통한 자기소개
2. **Skills** - 기술 스택 및 숙련도 시각화
3. **Timeline** - 학력 및 경력 타임라인
4. **Project** - 주요 프로젝트 소개
5. **Footer** - 연락처 및 링크

## 🛠️ 설치 및 실행

### 의존성 설치
```bash
npm install --legacy-peer-deps
```

### 개발 서버 실행
```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 확인하세요.

### 프로덕션 빌드
```bash
npm run build
npm start
```
